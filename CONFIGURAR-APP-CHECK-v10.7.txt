TEAM BULLS v10.7 — APP CHECK

O aplicativo está preparado para Firebase App Check com reCAPTCHA Enterprise.
A ativação completa depende de uma chave pública criada no seu projeto Firebase.

ARQUIVO A EDITAR
config_v10_7.js

CAMPO
appCheckSiteKey: ''

Depois de preencher a chave pública:
1. publique config_v10_7.js;
2. abra recuperar.html?v=10.7;
3. entre como treinador e aluno;
4. confira Central de operações → Sincronização → App Check;
5. monitore as métricas no Firebase;
6. somente depois ative a exigência para Firestore/Storage.

Não coloque no aplicativo:
- chave privada;
- JSON de conta de serviço;
- senha administrativa;
- token secreto de servidor.
